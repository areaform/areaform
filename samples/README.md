# Sample plans

Plans in the Areaform format ([JSON Schema](../packages/core/schema/v1/document.json)), each a whole Space. They are the demo Spaces on areaform.app, and the playground and the tests use them.

- `office.json`: an office building on three Levels, with meeting rooms, a kitchen, a garden, a car park and an Underlay; the playground opens with it.
- `expo.json`: an exhibition hall on three Levels, with booths, aisles, a stage, a café and loading docks.

Open one in the playground (`pnpm dev`, then **Import**), or load it in code with `fromJSON` from `@areaform/core`.
