# Security

Please do not report a security problem in a public issue.

Report it privately through GitHub: the **Security** tab → **Report a vulnerability**, or by mail to security@areaform.app. Say what is affected (a package and its version, or areaform.app), how to reproduce it and what it lets someone do.

We answer within three working days, keep you informed while we fix it, and credit you in the release notes if you want.

This covers the packages in this repository and the hosted product at areaform.app.
